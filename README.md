# slahManager

Бесплатная программа для Windows 11, которая подстраивает систему под игры: убирает задержку ввода, выравнивает пинг, вычищает предустановленный мусор и слежку. Всё, что она меняет, можно откатить.

**[Скачать последнюю версию](../../releases/latest)** — один файл `SlahManager.exe`, ничего устанавливать не нужно.

Новости, обновления и советы по бусту ПК: **[Telegram-канал PC Boost](https://t.me/pc_boost_R2)**

## Что умеет

- **Буст для игр.** Сам замечает запущенную игру (Steam, Epic, GOG, Riot, EA, Ubisoft, Rockstar, Xbox или любую из своего списка) и пока она идёт:
  - держит таймер Windows на 0,5 мс;
  - поднимает игре приоритет и не даёт Windows её притормаживать;
  - включает профиль питания на полную мощность (только от сети);
  - ставит на паузу фоновый поиск Wi-Fi, из-за которого раз в минуту прыгает пинг.

  Закрыл игру — всё вернулось как было.
- **Насыщенность в CS2.** Пока открыта CS2, цвета на экране насыщеннее. Работает с видеокартами NVIDIA и AMD.
- **Задержка ввода.** Твики таймера, USB, PCIe, парковки ядер, оптимизации для игр в окне.
- **Сеть и пинг.** Энергосбережение Wi-Fi и адаптеров, настройки Ethernet, проверка пинга до роутера и интернета.
- **Производительность, приватность, чистка.** Телеметрия, реклама в системе, предустановленные приложения.
- **Безопасность.** Перед первым изменением создаётся точка восстановления, у каждого твика сохраняется исходное значение, откат всего одной кнопкой в настройках.
- Русский и английский язык, работа в трее, автозапуск вместе с Windows.

## Запуск

1. Скачай `SlahManager.exe` из [релизов](../../releases/latest).
2. Запусти. Программа попросит права администратора: без них Windows не даст менять системные настройки.
3. Windows может показать предупреждение SmartScreen, потому что у файла нет цифровой подписи. Нажми «Подробнее» → «Выполнить в любом случае».

Требования: Windows 11, 64 бита.

## Честно о пинге

Пинг до игрового сервера зависит от расстояния до него, и программа его не уменьшит. Она убирает только то, что добавляет сам компьютер: энергосбережение сетевых адаптеров и фоновые сканирования Wi-Fi. Самый большой выигрыш в пинге даёт подключение по кабелю.

## Сборка из исходников

Нужен .NET 10 SDK.

```
dotnet build SlahManager.slnx
dotnet publish src/SlahManager/SlahManager.csproj -p:PublishProfile=SingleExe
```

Готовый файл появится в `dist/SlahManager.exe`. Устройство проекта описано в [PROJECT_MAP.md](PROJECT_MAP.md), правила разработки — в [PROJECT_RULES.md](PROJECT_RULES.md).
